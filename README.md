# 劳动争议律师 AI 助理 · Labor Dispute AI Agent

> 把律师每天处理的几百页材料，自动整理成可工作的案件资料包。
> 不是替律师判断，而是减少低价值劳动。

## 一句话定位

AI 律师助理 Agent：律师上传案件文件夹（仲裁材料 + 聊天记录 + 工资流水），15 分钟输出**案件摘要、时间线、证据目录、争议焦点、法律依据、庭审准备清单**。

## 为什么先做劳动争议

| 维度 | 劳动争议 | 婚姻家事 | 企业合同 |
|---|---|---|---|
| 案件结构化程度 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐ |
| 材料类型固定度 | 劳动合同/工资/社保/仲裁材料 | 聊天/转账/财产证明 | 合同文本差异大 |
| 律师高频痛点 | 每天处理大量同类案件 | 材料多而杂 | 审查标准不一 |
| 付费意愿 | 高（走量） | 高 | 很高（但竞争激烈） |

劳动争议案件高度结构化、材料类型固定、律师每天处理大量同类案件——是最容易验证 AI 价值的垂直切口。

## MVP 功能

1. **案件材料智能整理**（核心）：上传起诉状/答辩状/合同/聊天记录/邮件/证据照片 → 输出案件摘要（案件类型、当事人、争议金额、核心争议）
2. **自动生成案件时间轴**：从聊天记录和文档中提取关键事件并排序，省掉"把聊天记录看完整理事情经过"的时间
3. **证据目录 Agent**：按中国诉讼的证据三性（真实性/合法性/关联性）逐项分析，给出证明事项与风险提示（如缺少盖章页、缺原始载体）
4. **法律检索 Agent**：不是问"民法典第几条"，而是"对方拖欠货款但主张质量问题，有哪些类似裁判观点？"→ 检索法律法规/指导案例/裁判文书，输出类案观点
5. **庭审准备清单**：争议焦点 + 我方优势 + 风险点 + 可执行的准备事项

## 架构

```
                    律师
```

## 快速开始

需要 Python 3.10+ 和一个 OpenAI 兼容模型接口：

```powershell
py -3.10 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e ".[test]"
Copy-Item .env.example .env
```

设置 `LLM_API_KEY`、`LLM_BASE_URL` 和 `LLM_MODEL` 后启动：

```powershell
uvicorn legal_case_agent.app:app --host 127.0.0.1 --port 8000
```

浏览器打开 `http://127.0.0.1:8000`。运行测试：

```powershell
python -m pytest -v
```

支持 PDF、DOCX、TXT、PNG、JPG 和 JPEG，单文件默认 20 MB、单案件材料默认 200 MB、单次模型输入默认 200,000 字符（可通过 `MAX_FILE_MB`、`MAX_CASE_MB` 和 `MAX_MATERIAL_CHARS` 调整）。图片及扫描型 PDF 当前会标记为需要人工查看或 OCR；首版不内置 OCR、法律数据库检索、用户权限或云端存储。

> 默认仅监听本机。请勿将真实客户材料发送给未经律所审查的数据处理方或模型服务商。

## 技术栈建议

- 模型：国内模型 + 私有部署（通义千问 / DeepSeek / 智谱 GLM），法律数据不出境
- 法律数据源：国家法律法规数据库、裁判文书网、北大法宝 / 威科先行 / Alpha
- RAG：法律知识库 → Embedding → 检索 → LLM → 回答（带引用溯源）

## 定价思路

不卖"AI 律师"，卖"提高办案效率"：

- 个人律师：199～499 / 月
- 小律所：2000～5000 / 月
- 大所：私有部署

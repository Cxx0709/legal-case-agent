# 作品集项目状态

## 定位

这是一个使用合成劳动争议材料的个人作品集项目。系统输出是待人工核验的材料整理初稿，不是法律意见，也不处理真实客户案件。

## 当前状态

- 已有：TXT/DOCX/PDF 解析、逐文件解析状态、结构化报告 Schema、来源标签校验、模型失败重试。
- 已补充：服务重启时清理遗留 `running` 状态；报告页显示实际模型名称；合成演示数据。
- 已完成：自动化评测命令、Markdown 导出。
- 未完成：来源片段点击定位、人工修订、完整运行历史页面。

## 六周里程碑

1. 范围冻结与合成演示（当前）
2. 材料状态和结构化输出回归
3. 来源追溯、冲突与待核实展示
4. 合成评测集和自动报告
5. 人工审阅、导出和失败恢复体验
6. README、演示脚本和发布候选版本

演示脚本见 `docs/demo-script.md`。

所有评测数字必须来自固定版本的合成数据；不得写成法律准确率或真实业务效果。
